# UOMP Cloud Relay (deprecated)

> **Deprecated (2026-10).** The standalone UOMP Cloud Relay is retired. UOMP no longer provides a hosted public relay; remote Agents use Aegis Cloud for compute and Aegis Memory Gateway as the local entry point. This directory is kept as a historical reference.

The relay prototype validated Capability Tokens with only the Guard public key and forwarded requests. It did not store or read plaintext data. It is not part of the current reference implementation and is not wired into the `uomp` CLI.
