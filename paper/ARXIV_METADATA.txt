[Title]
Aegis OS: A Transactional Multi-Tenant Operating System Runtime for Eliminating Authorization Fatigue in Autonomous Coding Agents

[Authors]
Hui Zhao (huizhao@heurion.org)

[Comments]
18 pages, 3 TikZ figures, 11 tables. Open-source Rust implementation and reproducible benchmark suite available at https://github.com/heurion-org/aegis-os

[Abstract (Plain Text for arXiv Web Form — 1882 characters, strictly under the 1,920-character limit)]
Autonomous coding agents such as Google Antigravity (agy), Anthropic Claude Code (claude), and OpenAI Codex CLI (codex) execute multi-step software engineering workflows on developer workstations and cloud hosts. Existing agent execution environments face a Security-Autonomy Dilemma: operators must choose between per-action confirmation prompts, which interrupt workflows on 45%-57% of tool calls and induce severe authorization fatigue, or unconfined execution (--yolo / --dangerously-skip-permissions), which exposes host files, SSH/cloud credentials, and API tokens to prompt injection and hallucination risks. Furthermore, concurrent agents editing a shared working tree clobber one another's changes, while passing large artifacts inline through LLM context windows incurs high token overhead.

We present Aegis OS (aegis-os), a transactional, multi-tenant Agent Operating System Runtime in Rust exposed via the Model Context Protocol (MCP) and the Google Agent2Agent (A2A) protocol. Aegis OS shifts the authorization boundary from individual tool calls to transactional workspace boundaries. Each agent operates inside a kernel-enforced OS sandbox (macOS Seatbelt and Linux Bubblewrap namespaces with default-deny --tmpfs $HOME credential isolation and a Unix-socket egress bridge) backed by a Copy-on-Write (CoW) shadow workspace (APFS clonefile; single-open Linux FICLONE reflinks), an identity-pinned HTTP Egress Proxy with L7 method/path-scoped secret injection and outbound DLP payload inspection, and an A2A IPC bus with Content-Addressable Storage (CAS). Across 1,500 controlled tool calls and 28,087 real tool calls across 52 coding-agent session logs, Aegis OS reduces prompts by 94.19%-99.88% (controlled) and 90.7%-97.9% (real sessions, 1.12% IPR), lowers attack success rate across 80 red-team attacks in eight categories from 100.0% to 0.0% on macOS and Linux, clones 1,000-file (78.1 MB) workspaces in 6.3 ms on APFS and 15.6 ms on btrfs, and catches 10/10 syntactic and semantic merge conflicts.
