[Title]
Aegis OS: A Transactional Multi-Tenant Operating System Runtime for Eliminating Authorization Fatigue in Autonomous Coding Agents

[Authors]
Hui Zhao (huizhao@heurion.org)

[Comments]
14 pages, 3 TikZ figures, 9 tables. Open-source Rust implementation and reproducible benchmark suite available at https://github.com/heurion-org/aegis-os

[Abstract (Plain Text for arXiv Web Form — 1,685 characters, strictly under the 1,920-character limit)]
Autonomous coding agents such as Google Antigravity (agy), Anthropic Claude Code (claude), and OpenAI Codex CLI (codex) execute multi-step software engineering workflows on developer workstations and cloud hosts. Existing agent execution environments face a Security-Autonomy Dilemma: operators must choose between per-action confirmation prompts, which interrupt workflows on 45%-57% of tool calls in our benchmark trajectories and induce severe authorization fatigue, or unconfined execution (--yolo / --dangerously-skip-permissions), which exposes host files, SSH/cloud credentials, and API tokens to prompt injection and hallucination risks. Furthermore, concurrent agents editing a shared working tree clobber one another's changes, while passing large artifacts inline through LLM context windows incurs high token overhead.

We present Aegis OS (aegis-os), a transactional, multi-tenant Agent Operating System Runtime written in Rust and exposed via the Model Context Protocol (MCP) and the Google Agent2Agent (A2A) protocol. Aegis OS shifts the authorization boundary from individual tool calls to transactional workspace boundaries. Each agent operates inside a kernel-enforced OS sandbox (evaluated on macOS Seatbelt sandbox-exec, with a Linux Bubblewrap namespace backend and microVM control-plane interface) backed by an APFS Copy-on-Write (CoW) shadow workspace (libc::clonefile), an identity-pinned HTTP Egress Proxy with boundary secret injection, and an A2A-compliant Inter-Agent Communication (IPC) bus paired with Content-Addressable Storage (CAS). Inside its isolated CoW workspace and organization IPC bus, an agent executes with zero confirmation prompts; human approval or TTL-scoped session leases are required only when committing diffs to the host via an LCS-based Diff3 3-Way Merge Engine. Across 1,500 runtime tool calls spanning five trajectory templates and 40 end-to-end adversarial attacks, Aegis OS reduces human confirmation prompts by 94.19%-99.88%, lowers the attack success rate on evaluated vectors from 100.0% to 0.0%, clones 1,000-file (78.1 MB) workspaces in 6.28 ms (18.0x faster than full copy), and preserves 100% of disjoint multi-agent edits while catching 10/10 overlapping line conflicts.
