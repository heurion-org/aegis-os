[Title]
Aegis OS: A Transactional Multi-Tenant Operating System Runtime for Eliminating Authorization Fatigue in Autonomous Coding Agents

[Authors]
Hui Zhao (huizhao@heurion.org)

[Comments]
16 pages, 3 TikZ figures, 11 tables. Open-source Rust implementation and reproducible benchmark suite available at https://github.com/heurion-org/aegis-os

[Abstract (Plain Text for arXiv Web Form — 1893 characters, strictly under the 1,920-character limit)]
Autonomous coding agents such as Google Antigravity (agy), Anthropic Claude Code (claude), and OpenAI Codex CLI (codex) execute multi-step software engineering workflows on developer workstations and cloud hosts. Existing agent execution environments face a Security-Autonomy Dilemma: operators must choose between per-action confirmation prompts, which interrupt workflows on 45%-57% of tool calls in our benchmark trajectories and induce severe authorization fatigue, or unconfined execution (--yolo / --dangerously-skip-permissions), which exposes host files, SSH/cloud credentials, and API tokens to prompt injection and hallucination risks. Furthermore, concurrent agents editing a shared working tree clobber one another's changes, while passing large artifacts inline through LLM context windows incurs high token overhead.

We present Aegis OS (aegis-os), a transactional, multi-tenant Agent Operating System Runtime in Rust exposed via the Model Context Protocol (MCP) and the Google Agent2Agent (A2A) protocol. Aegis OS shifts the authorization boundary from individual tool calls to transactional workspace boundaries. Each agent operates inside a kernel-enforced OS sandbox (macOS Seatbelt and Linux Bubblewrap namespaces with a Unix-socket egress bridge) backed by a Copy-on-Write (CoW) shadow workspace (APFS clonefile; Linux FICLONE reflinks on btrfs/XFS with ext4 copy fallback), an identity-pinned HTTP Egress Proxy with boundary secret injection, and an A2A IPC bus with Content-Addressable Storage (CAS). Across 1,500 tool calls, an 80-attack red-team suite across eight threat categories, and component ablations, Aegis OS reduces prompts by 94.19%-99.88%, lowers attack success rate from 100.0% to 0.0%, clones 1,000-file (78.1 MB) workspaces in 6.28 ms on APFS, speeds up Linux workspace status by 77x (542 ms to 7.0 ms), and preserves 100% of disjoint multi-agent edits.
