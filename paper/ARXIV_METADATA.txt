[Title]
Aegis OS: A Transactional Multi-Tenant Operating System Runtime for Eliminating Authorization Fatigue in Autonomous Coding Agents

[Authors]
Hui Zhao (huizhao@heurion.org)

[Comments]
13 pages, 3 TikZ figures, 9 tables. Open-source Rust implementation and reproducible benchmark suite available at https://github.com/heurion-org/aegis-os

[Abstract (Plain Text for arXiv Web Form — 1,542 characters, strictly under the 1,920-character limit)]
Autonomous coding agents such as Google Antigravity (agy), Anthropic Claude Code (claude), and OpenAI Codex CLI (codex) increasingly execute multi-step software engineering workflows on developer hosts. However, existing execution environments face a Security-Autonomy Dilemma: Interactive Per-Action Prompting interrupts operators on 45%-57% of tool calls (causing severe authorization fatigue), whereas Unconfined Host Execution (--yolo / --dangerously-skip-permissions) exposes the host filesystem, SSH/cloud credentials, and API secrets to prompt injection and hallucination risks. Moreover, concurrent multi-agent edits on a shared tree cause race-condition file clobbering, and inline artifact passing incurs prohibitive LLM token overhead.

We present Aegis OS (aegis-os), a transactional, multi-tenant Agent Operating System Runtime written in Rust and exposed via the Model Context Protocol (MCP). Aegis OS shifts the security boundary from individual tool invocations to transactional workspace boundaries. Each agent principal runs inside an OS sandbox (macOS Seatbelt sandbox-exec or Linux Bubblewrap) backed by an APFS Copy-on-Write (CoW) shadow workspace (libc::clonefile), a Zero-Trust HTTP Egress Proxy with boundary secret injection, a Commit-Time Poisoning Guard, and an intra-organization IPC bus with Content-Addressable Storage (CAS). Across 1,500 live syscalls and 40 red-team attacks, Aegis OS reduces human prompts by 94.19%-99.88% (saving up to 71.6 min of wait time), blocks 100% of tested attacks (0.0% ASR), clones 1,000-file (78.1 MB) trees in 6.28 ms (18.0x faster than full copy with 94.0%-97.5% disk savings), preserves 100% of non-overlapping concurrent edits while catching 10/10 line conflicts, and cuts cross-agent artifact tokens by 99.85%.
